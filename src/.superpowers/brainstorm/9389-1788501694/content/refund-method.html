Q2. 환불 처리는 어떻게 할까요?

사용자가 환불 요청 후 실제 환불금 처리 방식을 선택해주세요.

A

즉시 자동 환불 (PortOne API 호출)

사용자가 환불 요청 제출 시, 서버가 바로 PortOne 환불 API를 호출해 자동 처리합니다.

처리 흐름

사용자 요청 제출
→
서버: PortOne 환불 API 즉시 호출
→
환불 완료

장점

  • 빠른 처리 — 관리자 개입 불필요
  • 사용자 경험 우수

단점

  • 검증 없이 즉시 환불 → 남용 위험
  • 부분환불 시 PG 정산 복잡
B

요청 접수 → 백오피스 수동 처리

사용자 요청은 DB에 저장만 하고, 백오피스에서 관리자가 확인 후 승인·환불 처리합니다.

처리 흐름

사용자 요청 제출
→
DB 저장 (환불요청 상태)
→
백오피스 관리자 확인
→
승인 후 환불

장점

  • 검증 단계 → 부정 환불 방지
  • 실무에서 가장 일반적인 방식
  • 구현 범위 명확하고 안전

단점

  • 처리 시간 소요 (관리자 확인 필요)

선택 후 터미널에 알려주세요.
