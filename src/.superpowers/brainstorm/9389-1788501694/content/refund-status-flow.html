Q1. 환불요청 버튼, 어떤 상태에서 보여야 하나요?

현재 주문 상태 흐름입니다. 환불요청 버튼이 표시되어야 할 상태를 모두 선택해주세요.

결제대기
pending
→
결제완료
paid
→
상품준비중
preparing
→
배송중
shipped
→
배송완료
delivered
→
취소됨
cancelled

※ 결제대기(pending)와 취소됨(cancelled)은 환불 버튼 불필요 — 아래 나머지 상태 중 선택

A

결제완료 (paid)

결제 직후 — 상품 준비 전 단계. 취소 개념에 가까움.

B

상품준비중 (preparing)

판매자가 상품을 준비 중인 단계.

C

배송중 (shipped)

이미 발송된 상태 — 반송이 필요한 환불.

D

배송완료 (delivered)

수령 후 환불 요청. 7일 경과 시 경고 메시지 표시 대상.

복수 선택 가능 — 원하는 상태를 모두 클릭 후 터미널에 알려주세요.
